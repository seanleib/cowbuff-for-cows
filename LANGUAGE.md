# Cowbuff Language (Cowbuff speaks this in every episode!)

| Cowbuff word | Means |
|---|---|
| Moo-ree | Hello! |
| Mooloo | Friend |
| Gruma | Grass |
| Sunna | Sun |
| Nom-nom | Eat / yummy |
| Mooshi | Good / nice |
| Wubba | Water |
| Rainu | Rain |
| Zoomoo | Run |
| Slumbo | Sleep |
| Dancu | Dance |
| Bellu | Bell |
| Haymo | Hay |
| Lunna | Moon |
| Tuk-moo | Thank you |
| Moo-bye | Goodbye |
| Ooma | Wow! |
| Fluttu | Butterfly |

Each episode shows the Cowbuff words with English subtitles, so everybody learns Cowbuff!

## Important
This show is FOR COWS. Cows can't read or understand people talk, so on screen Cowbuff only MOOS (real moo sounds, no English, no subtitles). The word list above is a helper for humans (like Hudson); the "Human words" button in the player turns the English helper on. Cow Buff the Movie is the human one — this series is the cow one.
